## Your website. A mobile experience.

**Appify** is a PROCESS IN platform focused on transforming existing websites into mobile applications. The product direction includes Android app generation, WordPress integration, push notifications, QR-related capabilities, previews, store-ready packaging and simplified build workflows.

Appify is listed in the official PROCESS IN product registry as a website-to-mobile-app conversion platform. **Feature implementation, platform support, pricing and commercial availability should be confirmed on the official website or with PROCESS IN.**

## Product capabilities and direction

| Area | Description |
|---|---|
| **Website-to-app** | Bring an existing website into an app-oriented experience |
| **Android** | Android app generation as a primary product direction |
| **WordPress** | Integration through a WordPress plugin offering |
| **Push notifications** | A communication channel for app users |
| **QR integration** | QR-based entry points and connections |
| **Preview experience** | Review an app experience before release |
| **Store-ready builds** | Packaging workflows aimed at app store submission |
| **Simplified building** | Reduce manual steps through a streamlined build flow |

> This table describes the known product scope and direction; it is not a claim that every item is production-ready. iOS support, marketplace approval, release timelines and individual feature availability are not independently verified.

## Who Appify is for

**Businesses with established websites** seeking a stronger mobile presence, **WordPress site owners** exploring an app channel, and **agencies** evaluating app delivery for clients.

## Product principles

- **Reuse existing content:** Make the website the starting point rather than rebuilding everything.
- **Brand continuity:** Keep a coherent business identity across web and mobile.
- **Practical distribution:** Support a workflow from preview toward a distributable app package.
- **Manageable experience:** Prioritize understandable controls and streamlined operations.
