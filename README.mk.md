# Appify — Претвори веб-страница во мобилна апликација

**Мобилни апликации · Android · WordPress · Push известувања**

[English](README.md) · [appify.mk](https://appify.mk) · [PROCESS IN](https://processin.mk)

**Appify** е платформа на PROCESS IN за претворање постојни веб-страници во мобилни апликации. Производот е насочен кон бизниси што сакаат мобилно присуство со свој бренд, без целосно повторно развивање на содржината.

![Appify](assets/appify-hero.svg)

## Функционалности и развојна насока

| Област | Намена |
|---|---|
| **Website-to-App** | Претворање постојна веб-страница во мобилно искуство |
| **Android** | Генерирање Android апликации |
| **WordPress** | Интеграција преку WordPress додаток |
| **Push известувања** | Комуникација со корисниците на апликацијата |
| **QR можности** | QR интеграции и поврзување |
| **Преглед** | Преглед на изгледот пред објавување |
| **Подготовка за продавници** | Генерирање пакети за поднесување во app stores |
| **Поедноставен процес** | Помалку рачни чекори при креирање апликација |

**Важно:** Ова е опис на производниот опсег и развојната насока, а не независна потврда дека секоја функција е продукциски завршена. Поддршката за iOS, достапноста и условите се потврдуваат директно со PROCESS IN.

## За кого е наменет?

За бизниси со постојни веб-страници, сопственици на WordPress сајтови и агенции што сакаат мобилни апликации за своите клиенти.
